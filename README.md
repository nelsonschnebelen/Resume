# Nelson Schnebelen | Customer Growth & Strategy

Static personal portfolio suitable for customer success and strategy conversations across restaurant technology and applied AI. HTML, CSS and optional JavaScript; no dependencies or build step.

## Preview
Run `python3 -m http.server 8000` from this folder, then open http://localhost:8000.

## Content
- `index.html`: general portfolio copy and contact links.
- `styles.css`: original dark / off-white / lime visual system and responsive layout.
- `script.js`: optional reveal animations; all content remains visible without JavaScript.
- `assets/nelson.jpg`: existing portrait.

The homepage intentionally omits employer-specific resumes, phone number, unconfirmed revenue metrics, and employer logos. No employer-specific pages or downloads are linked. Career facts are supplied by Nelson, not independently audited.

## Publication
No hosting configuration or deployment workflow is included. Review content and verify external video links before publishing. Do not assume a canonical domain.
